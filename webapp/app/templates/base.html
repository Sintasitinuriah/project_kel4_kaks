Panduan Alur Demo & Toggle Mode WAF

  1. Langkah 1 — Cek Status 4 Lapisan: Pastikan mode WAF aktif, role DB adalah app_user (bukan superuser), dan 6 produk utuh.
  2. Langkah 2 — Uji Mode WAF Blocking (On): Jalankan simulasi SQLi di Arena. Semua serangan otomatis ditahan di Layer 2 (WAF HTTP 403).
  3. Langkah 3 — Ubah WAF ke DetectionOnly: Jalankan perintah PowerShell di bawah, lalu refresh halaman ini.
  4. Langkah 4 — Uji Layer 3 & Layer 4: Jalankan ulang simulasi Auth Bypass, UNION Extract, dan DROP TABLE. Lihat bagaimana /secure menahan serangan di Layer 3 dan PostgreSQL menahan DROP/DELETE di Layer 4!
Mode WAF: DetectionOnly (Mendeteksi di log, meneruskan ke Layer 3 & 4)
$env:MODSEC_RULE_ENGINE="DetectionOnly"; docker compose up -d --force-recreate waf webapp
Mode WAF: Blocking (On — Memblokir SQLi dengan HTTP 403)
$env:MODSEC_RULE_ENGINE="On"; docker compose up -d --force-recreate waf webapp
Lihat Audit Log WAF secara Real-Time (PowerShell)
Get-Content .\logs\waf\audit.log -Tail 5 -Wait
